# 🎮 RetroConsole OS & Installer

**RetroConsole** — це повністю автономна, кіоск-орієнтована операційна система на базі Debian 13 (Trixie), розроблена для безпроблемного запуску класичних ігор та програм для MS-DOS і Windows 95/98 на сучасному та спадковому обладнанні.

Система випускається разом із **RetroConsole Custom Installer ISO** — кастомізованим інсталятором, що оформлений у стилі утиліт налаштування кінця 90-х років. Процес розгортання повністю автоматизований: від форматування диска до двофазного налаштування середовища (із ретро-слайдшоу у стилі Windows 98 Setup та підсумковим POST-екраном Award BIOS).

## ❓ Чому такі вимоги та як це працює?

> **RetroConsole не запускає Windows 98 безпосередньо на сучасному обладнанні.**

Сучасні материнські плати, NVMe-накопичувачі, UEFI та нові відеокарти вже давно не мають драйверів для Windows 9x. Замість прямого завантаження RetroConsole створює тонкий ізольований шар Linux-ядра, всередині якого працює програмно емульований ПК кінця 90-х років.

### Ключові переваги:
* **Незалежність від заліза:** Система працює однаково стабільно як на сучасному ігровому ПК, так і у віртуальній машині Hyper-V чи на компактному одноплатнику Raspberry Pi 5.
* **Відсутність проблем із драйверами:** Windows 98 «бачить» лише стандартні сумісні пристрої (Sound Blaster 16/AWE32, SoundFont MIDI, NE2000 network, VESA/S3 Graphics).
* **Повна беззвучність (Silent Boot):** Ви видалили всі тексти Linux, GRUB та systemd. При завантаженні ПК користувач бачить лише ретро-сплаш та екрани POST BIOS.

## 💿 Інсталятор RetroConsole (Custom Debian 13 ISO)

Установчий ISO-образ **RetroConsole** зібраний на базі `debian-13-netinst` і має повністю перероблену графічну та текстову схему:

1. **Фаза 1 (ISO Setup):** Очищений GTK-інсталятор без логотипів Debian, який виконує автоматичну розмітку та розгортання бази в режимі "Zero-Touch".
2. **Фаза 2 (First-Boot Setup):** Після першого перезавантаження запускається Plymouth-тема `retro-promo` зі слайд-шоу в стилі **Windows 98 Setup** (*"Відкиньтесь на спинку крісла й відпочиньте..."*). У фоні викачується образ Win98, компілюється DOSBox-X та налаштовується Samba (SMBv1) і SoundFont MIDI.
3. **Фінал:** Система перемикається на тему **Award BIOS**, автоматично перезавантажується та йде прямо в робочу Windows 98.

## ☁️ Незабаром: Хмарний сервіс RetroCloud

**RetroCloud** — це майбутня хмарна екосистема синхронізації та зберігання даних, створена спеціально для шанувальників ретро-ґеймінгу та класичних операційних систем.

Сервіс покликаний повністю усунути бар'єр між сучасними хмарними технологіями та легасі-системами, забезпечуючи автоматичне збереження прогресу в іграх, обмін ISO-образами та безшовний доступ до власної колекції ретро-софту з будь-якого куточка світу.

---

### 🚀 Заплановані можливості RetroCloud:

* **Кросплатформена синхронізація сейвів:** Автоматичний бекап та синхронізація збережень ігор між вашою RetroConsole, ПК, ноутбуком чи мобільними пристроями.
* **Міст між епохами:** Поєднання сучасних WebRTC/P2P та хмарних API із класичними мережевими протоколами (SMBv1, FTP, WebDAV) для прямої роботи всередині Windows 95/98 та MS-DOS.
* **Веб-панель керування:** Зручний браузерний інтерфейс для керування віртуальними дисками, ISO-бібліотекою та налаштуваннями без встановлення додаткового софту на клієнтські пристрої.
* **Захист від втрати даних:** Автоматична версійність та захист від пошкодження файлів дискет і жорстких дисків.
