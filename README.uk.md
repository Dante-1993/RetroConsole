🎮 RetroConsole OS & InstallerRetroConsole — це повністю автономна, кіоск-орієнтована операційна система на базі Debian 13 (Trixie), розроблена для безпроблемного запуску класичних ігор та програм для MS-DOS і Windows 95/98 на сучасному та спадковому обладнанні.Система випускається разом із RetroConsole Custom Installer ISO — кастомізованим інсталятором, що оформлений у стилі утиліт налаштування кінця 90-х років. Процес розгортання повністю автоматизований: від форматування диска до двофазного налаштування середовища (із ретро-слайдшоу у стилі Windows 98 Setup та підсумковим POST-екраном Award BIOS).💻 Системні вимогиПараметрМінімальні вимогиРекомендовані вимогиПроцесор (CPU)64-бітний (x86_64 / ARM64), 2 ядра4-ядерний CPU (Ryzen / Core i5+)Оперативна пам'ять (RAM)2 ГБ4 ГБ або більшеДисковий простір8 ГБ (HDD)16 ГБ (SSD)ВідеокартаЗ підтримкою OpenGL 2.1З підтримкою OpenGL 3.x+ / VulkanРоздільна здатність1024×7681920×1080МережаДля завантаження компонентів під час першого старту100/1000 Mbit Ethernet або Wi-FiПримітка щодо продуктивності: Завдяки динамічній рекомпіляції ядра (core=dynamic_x86), сам процес емуляції DOSBox-X є надзвичайно легким. Замість прямого завантаження RetroConsole створює тонкий ізольований шар Linux-ядра, всередині якого працює програмно емульований ПК кінця 90-х років.Переваги цього підходу:Незалежність від заліза: Система працює однаково стабільно як на сучасному ігровому ПК 2026 року, так і у віртуальній машині Hyper-V чи на компактному одноплатнику Raspberry Pi.Відсутність проблем із драйверами: Windows 98 «бачить» лише стандартні сумісні пристрої (Sound Blaster 16/AWE32, SoundFont MIDI, NE2000 network, VESA/S3 Graphics).Повна беззвучність (Silent Boot): Ви видалили всі тексти Linux, GRUB та systemd. При завантаженні ПК користувач бачить лише ретро-сплаш та екрани POST BIOS.💿 Інсталятор RetroConsole (Custom Debian 13 ISO)Установчий ISO-образ RetroConsole зібраний на базі debian-13-netinst і має повністю перероблену графічну та текстову схему:Фаза 1 (ISO Setup): Очищений GTK-інсталятор без логотипів Debian, який виконує автоматичну розмітку та розгортання бази в режимі "Zero-Touch".Фаза 2 (First-Boot Setup): Після першого перезавантаження запускається Plymouth-тема retro-promo зі слайд-шоу в стилі Windows 98 Setup ("Відкиньтесь на спинку крісла й відпочиньте..."). У фоні викачується образ Win98, компілюється DOSBox-X та налаштовується Samba (SMBv1) і SoundFont MIDI.Фінал: Система перемикається на тему Award BIOS і автоматично завантажується прямо в робочу Windows 98.☁️ Модуль RetroCloud (Синхронізація файлів)Для передачі сейвів, ISO-образів та ігор у системі інтегровано модуль RetroCloud.Вимоги до клієнта: Сучасний веб-браузер із підтримкою WebRTC (Chrome, Firefox, Edge, Safari).Принцип роботи: Дозволяє синхронізувати каталог /home/retro/retroconsole/share між ретро-консоллю та іншими пристроями у локальній мережі або через P2P-з'єднання без встановлення стороннього софту на ретро-систему.
